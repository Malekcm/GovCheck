# Federal opportunity capture workflow

GovCheck executes the complete versioned research instructions and all 93 questions through its server-side research orchestrator. Read RUNTIME.md and docs/PHASE2.md for configuration and constraints.

The original complete user-owned package was reviewed locally. This public runtime distribution retains its instructions, references, generic templates and layout scripts. Company-specific data and the historical customer report remain outside this repository. GovCheck always loads the selected configured company profile and never assumes a particular firm or reuses old opportunity facts.
